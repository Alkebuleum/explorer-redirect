# explorer.alkebuleum.com → alkescan.com

GitHub Pages site whose only job is to redirect the old explorer domain to
[AlkeScan](https://alkescan.com), keeping the path so old links still work
(e.g. `/address/0x…` → `https://alkescan.com/address/0x…`).

`404.html` is the same page, so every path redirects, not just `/`.
